### 说明

```
Translucid（透译）做两件事：把常用网页应用的界面换成你想要的任意语言，以及用你自己的大模型 API 把网页翻译成简体中文。扩展没有服务器，不收集遥测，所有设置和译文都保存在你的浏览器里。

【站点本地化：网页应用的界面，换成任意语言】
很多好用的网页应用没有你的母语界面。打开这个网站，点扩展图标里的「一键本地化此站点」：
• 一键扫描：自动打开设置分区、菜单和下拉列表，找出界面文字。只打开导航和菜单，不改任何设置，结束后页面恢复原状；第一次扫描前会征求你的同意，按 Esc 随时停止。
• 按结构翻译：文字按「界面 › 分区 › 问题 › 选项」成组发给模型，同一个词在不同问题下可以有不同的正确译法（例如「文字大小」里的 Medium 译作「中」，「页面宽度」里的 Medium 译作「适中」）。
• 先审核、后发送：会话、笔记、账户名等个人内容不会被收集；你在工作台审核找到的文字，并在发送前看到完整的请求内容。
• 本地保存：生成的语言包存在本机，以后打开网站直接显示目标语言，不再请求模型；日常使用中出现的新界面文字会记下来等你审核（可关闭）。
• 手动调整范围：可以圈选要收集的区域、排除你自己的内容；支持导出和导入语言包。

【网页翻译：双语阅读任意网页】
• 双语对照或只看译文，Alt+A 翻译 / 恢复，Alt+S 切换显示方式。
• 优先翻译眼前的内容，流式逐段显示；保留链接、加粗、代码等格式；本地缓存，刷新不重复请求。
• 场景专家（通用、科技、新闻、学术、严谨、社区、小说）按网站自动匹配，可编辑；全局和按站点的术语表。
• 右键菜单「精翻此段」。

【自带 API Key，多服务商】
支持 DeepSeek、智谱 GLM、Z.ai、Gemini、Anthropic Claude、OpenCode、OpenRouter、NVIDIA NIM，以及任意 OpenAI 兼容接口。正文、短文本、精翻、备用可分别选用不同服务商；按各服务商的限额自动限流和退避，主服务商出错时转给备用。可选的谷歌 / 微软免费机翻（非官方接口，默认关闭）只用于按钮、菜单这类短文本。

【隐私】
扩展只把要翻译的文字发给你自己配置的服务商；生成语言包时只发送你确认过的界面文字。API Key 保存在浏览器本地，不进入网页。完整的数据流见隐私说明。

开源（MIT）：https://github.com/PIDEAN/translucid
界面语言为简体中文。
```

## 隐私权（Privacy practices）

### 单一用途

```
把网页内容和网页应用的界面翻译成用户选择的语言：网页翻译把页面文字译成简体中文并以双语或只看译文显示；站点本地化为用户选择的网站生成并应用本地的界面语言包。两者都由用户发起，只把要翻译的文字发给用户自己配置的大模型服务商。
```

### 权限理由

| 权限 | 理由 |
|---|---|
| `storage` | 保存用户的设置、服务商配置（含用户自己的 API Key）、用量统计和站点语言包，全部在本机。 |
| `unlimitedStorage` | 翻译缓存（IndexedDB，最多约 6 万条）和站点语言包可能超过默认配额；缓存可在设置页一键清空。 |
| `contextMenus` | 提供右键菜单「精翻此段」，对选中的段落用更好的模型重新翻译。 |
| `tabs` | 读取当前标签页的网址和域名，用于在弹出菜单里显示这个网站的翻译状态和语言包，并把站点规则、语言包限定在对应网站。 |
| `scripting` | 只在用户已有语言包的网站上注册界面译文脚本；用户点「一键本地化」或「调整范围」时，在当前标签页注入扫描或圈选工具。 |
| 主机权限 `<all_urls>` | 翻译用户打开的任意网页需要读取并在原处显示页面文字；后台需要向用户自己配置的任意大模型接口（OpenAI 兼容地址由用户填写）发起请求。扩展不会在用户没有操作时读取或发送页面内容。 |

### 远程代码

否。所有代码都打包在扩展内，不加载或执行远程脚本；模型返回的译文只作为纯文本插入页面，从不当作 HTML 或代码执行。

### 数据使用

勾选：

- **网站内容**：翻译时把页面上的文字、页面标题发给用户配置的服务商；生成语言包时只发送用户确认过的界面文字和网站域名。
- **身份验证信息**：用户自己的 API Key 保存在本机，只随请求发给对应的服务商，用于身份验证。

其余类别不勾选：扩展不收集个人身份信息、健康、财务、个人通讯、位置、用户活动（点击、键入）；不发送浏览记录（只有正在翻译的页面标题作为翻译上下文，算在网站内容里）。

三项声明全部勾选：不向第三方出售或转让用户数据（用户选择的服务商仅用于完成翻译这一核心功能）；不将数据用于与核心功能无关的目的；不用于判断信用或发放贷款。

## 测试说明（给审核人员）

```
网页翻译和语言包生成需要用户自己的大模型 API Key：点扩展图标右上角的齿轮打开「配置 › 服务商与路由」，展开任一服务商（例如 DeepSeek，或任意 OpenAI 兼容接口），填入 Key 并保存。之后在任意英文网页按 Alt+A 即可看到双语翻译。站点本地化：在网页应用（例如带设置页的网站）上点扩展图标 →「本地化」→「一键本地化此站点」，扫描结束后在工作台审核并生成。界面为简体中文。
```

## 以后更新

首次上架之后，更新可以用 Chrome Web Store API v2 自动上传和提交（WXT 的 `wxt submit`）。这需要在 Google Cloud 创建 OAuth 凭据，并把客户端 ID、密钥和 refresh token 放进环境变量；这些值不要写进仓库。每次更新都要先提高 `package.json` 里的版本号。
