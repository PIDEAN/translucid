# 商店被拒（Yellow Argon / 关键词堆砌）：修改与重新提交

## 为什么被拒

审核指出的违规内容是说明里这一串服务商名称：

> DeepSeek、智谱 GLM、Z.ai、Gemini、Anthropic Claude、OpenCode、OpenRouter、NVIDIA NIM

Chrome 应用商店的[垃圾内容政策](https://developer.chrome.com/webstore/spam-faq#keyword-spam)不允许在说明里罗列一长串品牌名或关键词。即使这些都是扩展真实支持的服务，连续堆在一起也会被判定为「为了搜索排名而堆砌关键词」。

用同样的标准看，说明里还有一处风险：「场景专家（通用、科技、新闻、学术、严谨、社区、小说）」也是一串并列的词。这次一并改掉，避免下次因为它再被拒一轮。

扩展本身（代码、权限、隐私申报）没有问题，这次**只需要改商店说明**，不用重新上传 zip。

## 怎么改（约 5 分钟）

1. 打开[开发者后台](https://chrome.google.com/webstore/devconsole)，进入 Translucid 透译 →「商店信息」（Store listing）。
2. 把「说明」（Description）整段删掉，粘贴下面「新的说明」里的全部文字。
3. 其他字段不用动：名称、摘要、截图、宣传图、隐私权页、分发都保持原样。
   - 截图里弹出菜单底部会显示「DeepSeek · deepseek-flash」，这是界面上的实际内容，不算堆砌，不用换。
4. 点右上角「保存草稿」，再点「提交审核」。
   - 如果弹出「Publishing will be delayed」（广泛主机权限需要深度审核），照常点「Submit for review」。
5. 等待审核结果邮件。

## 新的说明（整段复制粘贴）

和原来相比只改了两处：

- 「自带 API Key，多服务商」一节：去掉 8 个服务商名称，改为「内置多家常见服务商的预设，也可以接入任意 OpenAI 兼容接口」。
- 「场景专家（……七个词）」改为一句描述：「按网站类型自动选择合适的翻译风格」。

```
Translucid（透译）做两件事：把常用网页应用的界面换成你想要的任意语言，以及用你自己的大模型 API 把网页翻译成简体中文。扩展没有服务器，不收集遥测，所有设置和译文都保存在你的浏览器里。

【站点本地化：网页应用的界面，换成任意语言】
很多好用的网页应用没有你的母语界面。打开这个网站，点扩展图标里的「一键本地化此站点」：
• 一键扫描：自动打开设置分区、菜单和下拉列表，找出界面文字。只打开导航和菜单，不改任何设置，结束后页面恢复原状；第一次扫描前会征求你的同意，按 Esc 随时停止。
• 按结构翻译：文字按「界面 › 分区 › 问题 › 选项」成组发给模型，同一个词在不同问题下可以有不同的正确译法（例如「文字大小」里的 Medium 译作「中」，「页面宽度」里的 Medium 译作「适中」）。
• 先审核、后发送：会话、笔记、账户名等个人内容不会被收集；你在工作台审核找到的文字，并在发送前看到完整的请求内容。
• 本地保存：生成的语言包存在本机，以后打开网站直接显示目标语言，不再请求模型；日常使用中出现的新界面文字会记下来等你审核（可关闭）。
• 手动调整范围：可以圈选要收集的区域、排除你自己的内容；支持导出和导入语言包。

【网页翻译：双语阅读任意网页】
• 双语对照或只看译文，Alt+A 翻译 / 恢复，Alt+S 切换显示方式。
• 优先翻译眼前的内容，流式逐段显示；保留链接、加粗、代码等格式；本地缓存，刷新不重复请求。
• 按网站类型自动选择合适的翻译风格（例如技术文档和新闻用不同的规则），规则可以自己编辑；支持全局和按网站的术语表。
• 右键菜单「精翻此段」。

【使用你自己的大模型】
填入你在大模型服务商那里申请的 API Key 即可使用，内置多家常见服务商的预设，也可以接入任意 OpenAI 兼容接口。正文、短文本、精翻和备用可以分别选择服务商；遇到限流会自动等待重试，主服务商出错时转给备用。另有可选的免费机器翻译，只用于按钮、菜单这类短文本，默认关闭。

【隐私】
扩展只把要翻译的文字发给你自己配置的服务商；生成语言包时只发送你确认过的界面文字。API Key 保存在浏览器本地，不进入网页。完整的数据流见隐私说明。

开源（MIT）：https://github.com/PIDEAN/translucid
界面语言为简体中文。
```

## 如果还想多一层保险（可选）

- 可以在后台的「申诉 / 回复审核」里附一句说明，不是必需的：

  > We removed the list of provider names from the description. The extension works with any OpenAI-compatible endpoint the user configures; the description now describes this generically.

- 想让用户知道具体支持哪些服务商，可以引导到 GitHub README 查看完整列表。商店说明里不要再列出来。

## 以后写商店文案的规则

- 不要并列超过两三个品牌名、产品名或同类关键词。用一句概括代替，比如「多家常见服务商」「多种网站类型」。
- 不要在说明里重复堆叠同义词，比如「翻译、翻译插件、翻译工具、网页翻译、双语翻译」。
- 截图和宣传图里同样不要堆关键词。
